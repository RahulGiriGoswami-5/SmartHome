# 🚀 HOW TO ACCESS THE APPLICATION    

## ⚠️ DO NOT TRY TO OPEN THE EXE DIRECTLY FROM GITHUB

GitHub does **not** allow the application to run directly from the repository.

### Follow these 4 simple steps:

### 1️⃣ DOWNLOAD THE ZIP

Go to the **Releases/Files section of this repository** and download:

**`SmartHome.cpp.zip`**

> ⬇️ Download the ZIP file to your Windows computer.

---

### 2️⃣ EXTRACT THE ZIP

After downloading:

**Right-click the ZIP → Extract All → Extract**

Open the newly extracted folder.

⚠️ **Do not run the EXE while it is still inside the ZIP file.**

---

### 3️⃣ RUN THE APPLICATION

Inside the extracted folder, find:
SmartHomeControlSystem.exe

### 4️⃣ WINDOWS SECURITY WARNING

Windows may display **"Windows protected your PC"** when you open the application.

If this appears:

**Click `More info` → then click `Run anyway`**

The application will then open normally.
